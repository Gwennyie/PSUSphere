---
# <div align = "center"> All about PSUSphere 
<p>💻 PSUSphere is a Django-based web application that explores university's information based on: College, Academic Programs, Student Organizations, Students, and Organization Memberships.

It allows administrators to manage student records and organization memberships through the Django Admin interface, while also supporting database relationships (SQLite), search and filtering, and automated sample data generation (Faker).

---
# <div align = "center"> List of Features</div>
 
<p><h4>
 
🏫 Manage colleges and their information

📚 Manage academic programs and their associated colleges

👥 Manage student organizations

ℹ️ Manage student information and academic programs

🙋‍♀️ Manage organization memberships

🔎 Search and filter records through the Django Admin

📊 Generate initial sample data using Faker

📝 Use Django's built-in administration system for managing records </h4>
